Frequently Asked Questions

Q1: What do I need to run the calculators?

A1: Only a current web browser with JavaScript enabled. No plugins or installations are required, and the calculators work on desktop and mobile devices.

Q2: A calculator does not show results. What should I do?

A2: Reload the page, check that JavaScript is enabled and that all inputs are valid numbers, then try another up-to-date browser. If the problem persists, contact us with the page URL and the inputs you used.

Q3: Where can I find the methods behind each calculator?

A3: Browse the pricing, calibration and risk management hubs, or read the research papers.
